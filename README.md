# ASP.NET Lab Manual Solutions 🧑‍💻

This repository contains solutions to practical lab exercises from the ASP.NET Lab Manual, built using C# and Visual Studio. It includes examples covering key programming concepts.

---

## 💡 Technologies Used

- **ASP.NET Web Forms**
- **C#**
- **Visual Studio IDE**

---

## 🔧 Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Arman-Gilani/ASP.NET-PROGRAMS-SOLUTION.git
````

2. Open the `.sln` file in **Visual Studio**.

3. Build the solution (`Ctrl + Shift + B`) and run it.

4. Make sure your connection string in `Web.config` is configured correctly for your SQL Server.
